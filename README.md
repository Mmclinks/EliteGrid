# EliteGrid

**EliteGrid** — это система управления узлами, контактами и продуктами, основанная на Django и Django REST Framework. Проект включает управление звеньями, продуктами, контактами и поставщиками с поддержкой авторизации и фильтрации по различным параметрам.

## Описание

Проект включает несколько моделей:
- **GridNode** — узлы, которые могут быть разных типов: заводы, розничные сети и ИП.
- **NodeContact** — информация о контактах для каждого узла.
- **EliteProduct** — продукты, которые связаны с узлами.

Также реализован API с помощью Django REST Framework, который позволяет взаимодействовать с данными через HTTP-запросы.
